Flash pocket-dial

Install the pocket-dial SIP PBX firmware onto your ESP32-S3 board over USB, straight from this page. No toolchain, no downloads.

This browser can't talk to serial devices.

Flashing needs the Web Serial API, which today only Chrome, Edge, and Opera on desktop support. Firefox, Safari, and all mobile browsers do not.

Open this page in Chrome or Edge on a desktop, or flash from the command line with the esptool instructions in FLASHING.md.

1

Connect your board

Plug it into USB, then pick its port in the browser prompt.

Close any serial monitor first.

On Windows a COM port can only be open in one program at a time. If idf.py monitor, PuTTY, the Arduino IDE, or a VS Code serial terminal has the port, connecting here fails with “Failed to open serial port”.

Pick your board

Every published build targets the ESP32-S3, so the chip alone can't say which one you have. The firmware differs by how it reaches the network.

Picking the wrong one gives you a board that boots but never gets on the network. Ethernet builds have no Wi-Fi at all, and the display build expects the Guition panel wired up.

Set Wi-Fi, AP security and SIP registrar mode while flashing

Writes a small settings blob to the board's cfgseed partition. The firmware reads it once on the next boot, copies what's flagged into NVS, and then ignores it until the flasher writes a newer one. Until first-use setup replaces the default admin login, this is the only way to hand a passphrase to the headless Wi-Fi access point build, which has no screen to show one on. After that, the dashboard can read and change it. Today it is also the only way to set the SIP registrar's admission mode on any board before its first boot.

Device settings to write

Switching the access point to WPA2 breaks every existing connection. Phones, ATAs and laptops already associated with the open network cannot rejoin until each one is re-paired with the new passphrase. Write the passphrase down before you flash — on a headless board before first-use setup, the only other copy is the serial log. After that, the dashboard can show it.

8–63 printable ASCII characters, the WPA2 limits. Generate makes a 20-character one from an alphabet with no 0/O, 1/I/L or U, because it gets read off a small screen and retyped into a phone. Leave it empty to keep the board's current passphrase.

Optional. Leave the SSID empty to keep whichever network the board already has saved; leave the password empty for an open network.

Who is allowed to register as an extension. A board that has never been told otherwise runs in learn, so on a fresh board Leave as is means learn. There is no open mode any more: accepting any endpoint with no credential let anyone on the link register as any extension, and firmware that finds it stored switches the board to learn.
Learn: trust-on-first-use. An unknown device is adopted unverified; its extension is locked to it when it registers again at least 30 s later, if no other device claimed that extension first (never for a phone on another subnet, or one sharing a router's MAC), while devices already secured are digest-enforced as usual. Your phones register with nothing to configure.
Secure: every REGISTER is digest-challenged, so an extension can only be claimed by something that knows its secret. An extension with no secret stored yet cannot register at all — the registrar answers Extension Not Provisioned — so provision your extensions before you switch a working system over.

Learn trusts first contact. Anything that can reach the PBX can claim any extension that is not yet locked or secured. Adopt your phones on a trusted or WPA2 link; for the strongest setting, secure them and switch to Secure from the dashboard.

The seed is written on both Full flash and App only. The Ethernet build has no Wi-Fi radio, so its access-point and Wi-Fi fields have no effect there. A release whose partition table predates this feature has no cfgseed partition for the firmware to read. The page still writes the seed to the fallback address and reports the passphrase as written, but the firmware ignores it. Run a Full flash so the new partition table lands too.

Flash your own build instead

For images you built yourself with idf.py build. Leave a slot empty to skip that region. Offsets default to this project's layout — take the real ones from your build's flash_args if you've changed the partition table.
