Core Performance Metrics

High-efficiency engineering designed specifically to fit on resource-constrained microcontrollers and local host environments.

Open By Default, Locked If You Want

Out of the box any SIP endpoint registers immediately. No username, no password, nothing to configure. Turn on SIP digest auth (RFC 2617) when you are ready, with a Learn mode that adopts an existing phone fleet without re-provisioning it. Either way: do not expose SIP or the dashboard to the public Internet.

Direct RTP Media Flow

Voice data flows peer-to-peer directly between devices. By default the server handles only SIP signalling and never touches call audio, which is what keeps RAM use and latency down. The optional conference mixer is the one exception, and it is off unless you build it in.

Hardened C++17 Core

Features memory-safe header parsing, bounded string modifications, and dynamic_cast failure handling to prevent Xtensa reboots or desktop crashes.

Multi-Platform Sockets

Uses standard POSIX socket abstractions on Linux, Winsock on Windows, and native lwIP wrappers on ESP32 (running in a dedicated FreeRTOS 8KB stack task).

It Behaves Like a Real PBX

Everything below runs on the microcontroller itself — no cloud service, no companion server, no per-seat licence.

Transfer, Blind & Attended

Blind transfer hands the call straight over. Attended transfer lets you consult first, then splice the two parties together with REFER + Replaces (RFC 3891) — the transferor drops out and a later hang-up from either side still tears the call down cleanly.

Park & Retrieve

Dial a free orbit in 700–709 to park a call; anyone can dial the same orbit from any handset to pick it up. Useful for “grab this on the phone in the back” without an intercom.

Call Pickup

*8 answers whatever is ringing in your pickup group; **<ext> answers one specific extension. Stops the walk across the room to a ringing desk.

Ring Groups & Hunting

Ring every member at once, or hunt down the list to the first phone that answers. Unanswered legs are cancelled properly rather than left ringing.

Forwarding & DND

Forward unconditionally, on busy, or on no-answer (CFU / CFB / CFNA), plus do-not-disturb with dial codes to toggle it from the handset.

Paging Zones

Dial 980–989 to talk out of a zone of phones at once, or 999 to page everything. Star codes cover the rest — echo test, DND toggle and friends.

🔐 Deployment Guidelines

Critical specifications for running in development and field deployments:

TRUST MODEL

Flat trusted networks by default: out of the box the registrar accepts any local device and the Wi-Fi access point is open, which is what makes it zero-friction for isolated labs, temporary networks and demos. Treat that default as “everyone in radio range is a peer”.

HARDENING

Opt-in, not automatic: WPA2 on the access point (one change that encrypts the dashboard, SIP signalling and call audio), SIP digest authentication with a Learn mode for adopting an existing phone fleet, and an admin PIN with a dark-by-default admin plane are all available and all off until you turn them on. See the threat model and setup guide.

SECURITY LIMIT

WAN Isolation: Do not bind or port-forward UDP port 5060 or TCP port 8080 to public internet interfaces. Always run within secure local subnets or isolated VPN segments.

RELEASES

v1.4.1 is the current stable release and carries everything on this page — the call features, the admin PIN and hardened dashboard, and the access-point and registrar controls. Flash it from the browser flasher or grab the images from the releases page. A v1.5.0 beta is also published as a pre-release and selectable in the flasher; it is host-tested, not yet bench-proven. main moves ahead of the newest tag between releases, so build from source only if you want something that landed after it.
