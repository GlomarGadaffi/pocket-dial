Backup and restore

Export downloads the device settings as JSON. Without a password the file has no encrypted secrets block. A password adds that block and needs an owner login. The password must be at least 12 characters.

Import replaces the settings the file contains. It does not merge them. Whatever the device cannot take back is listed as skipped.

Factory reset

Returns the device to its install-time seed settings and reboots it. Erases stored logins, credentials, call history and saved Wi-Fi. Owner login required.

Notifications

SMTP settings for alert email. Save stays off until the current settings load. A blank password, service key or CA certificate keeps the stored one.
