Adopted devices

Phones seen while in Learn mode. Secure locks one to its extension and starts enforcing digest auth for it; Forget drops the record so the phone is re-adopted on its next registration. A locked row is bound to its phone's MAC. A shared row (a NAT router, or a phone moved while unlocked) never locks: Forget it so the right phone can lock.

Phone provisioning URLs

Phones fetch these URLs themselves. This page does not push configuration to a phone. The board serves a file only for an adopted MAC, or for the fixed master and bootstrap names.
URL patternFormat
/config/<mac>.cfgYealink (not hardware-verified)
/config/000000000000.cfgPolycom master (fixed name)
/config/<mac>-phone.cfgPolycom, per phone
/config/spa<mac>.cfgCisco SPA, macro-expanded
/config/spa<model>.cfgCisco SPA, keyed by model
/config/snom<mac>.xmlsnom
/config/cfg<mac>.xmlXML
<mac> is 12 hex digits with no colons.
