Routing

Dial plan rules that send outside and internal numbers, and SBC mode. E911 notification is in Security.

Dial plan 0rules

Ordered rules, first match wins. X matches one digit; a trailing * matches the rest. Rules are checked after the reserved feature extensions. Emergency calls (911, 933) are classified before the dial plan.

Add a rule

New rules go to the end of the list.

Prepend nothing: on a trunk rule, leave the prepend field blank. The dialed digits go out with only the strip applied. It is still saved as a rule, never a delete.

Reserved extensions

Fixed in firmware and checked before any dial-plan rule: park orbits 700–709 and paging zones 980–989, plus the fixed feature codes. A rule cannot use them as its pattern.

SBC mode

Border-element mode: calls the dial plan does not claim, including extension-to-extension, go out the selected trunk exactly as dialed. Emergency calls (911, 933) are classified first. A changed route takes effect on next reboot.
