Security

Operator login

Admin controls stay locked until you log in. The board ships with a default login until you set a real one.

·Logged in

Admin login

Change the admin username and password. Both are required.

DTMF admin PIN

The phone-keypad admin menu stays off until a PIN is set. Enter 4 to 16 digits.

Owner login

Owner-only: OTA upload, factory reset, coredump download, media TX, and backup export or import with a password. Once an owner login exists, Sysop sessions cannot use them.

Wi-Fi access point security

This board's own access point carries the dashboard, SIP signalling and call audio. Left open, anyone in radio range can join and record calls. WPA2 encrypts all three at once.

· BREAKING CHANGE Turning WPA2 on means every phone already on this access point must re-join using the passphrase below. Nothing changes until the access point next comes up.
Current mode—

Phone registration mode (Learn or Secure) is set in Devices.

E911 notification

Who is told on site when somebody dials 911. A factory reset clears these.
