# Files tools/gen_index_html.py inlines into src/Helpers/index_html.h.
# One path per line, relative to web/. '#' starts a comment. Order matters for
# the JS files (they become one <script> in this order) and must match the
# <script src> order in index.html. Every sections/NN-name.html needs a matching
# <section id="sec-name" hidden></section> in index.html, or a <div id="NAME-slot"></div>
# in an unguarded fragment.
# A line '@if NAME' (or '@if NAME!=0' for a 0/1 macro) before a path guards that one file: ESP builds
# compile it out unless the macro is set. '@unless NAME' is the inverse (compiled out when the macro is
# set). Guard lines stack as AND. A guarded fragment that owns a <section> takes the section tags with
# it. '@only NAME' is the strict '@if': compiled in only when the macro is set, with no host fallback
# (the desktop/host build never carries it); it stands alone. See tools/gen_index_html.py.
# POCKETDIAL_PROFILE_SBC (main/CMakeLists.txt): 3CX owns routing, call handling, audio and DID mapping,
# so those pages are compiled out and the SBC copy (05-sbc) is compiled in, on SBC builds only.
